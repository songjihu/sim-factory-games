# 掌舵人 · 文字经营游戏

原创免费试玩原型。

- 游戏目录：https://songjihu.github.io/sim-factory-games/
- 支行岁月：https://songjihu.github.io/sim-factory-games/games/bank/

部署：Settings → Pages → Deploy from a branch → main → /(root)。

新增游戏放在 games/<游戏标识>/，通用资源放在 shared/。各游戏单独设置存档键、Service Worker 作用域与缓存前缀。

当前为 v0.1 原型，数字为虚构游戏模型。
