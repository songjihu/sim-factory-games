# 开个面馆 · 山城清晨

山城竹器巷里的一碗小面。外婆住院了，面馆交到你手上：三十天，六千块的债。

**玩法与作者系列里其它作品完全不同**：这是实时时间管理动作游戏——接单、煮面、掐着绿区捞面、按配方顺序打佐料，手快有手慢无。灶上的火不等人。

**在线玩**：双击 `index.html` 即玩；部署到任意静态托管后可安装到手机主屏、离线可玩。

## 玩法

- 客人坐下 → **点客人**下面 → 进度条进**绿区**点灶眼捞面（早了夹生、晚了坨）
- 面进调味台 → 按订单**配方顺序**点佐料（特辣多放油辣子，点错扣品质）
- 调完自动出餐。连击加钱，口碑引流，客人等太久会走
- 每天收摊结算，利润买设备、上新菜；第 10/20/30 天有还款硬指标
- 常客 4 位各有三条故事线：他们来吃面，这碗得做到合格以上，情分才算是处下了
- 18 个随机事件（雨天/连锁店开业/跳闸/职业差评师……），6 个结局，判定看欠款、口碑、常客线与存款

## 目录

- `index.html`：游戏本体，单文件零依赖
- `sw.js` / `manifest.webmanifest` / `icon.svg`：PWA 安装与离线
- `tests/smoke.js`：引擎回归 + 200 局机器人平衡模拟（`node tests/smoke.js`）
- `tests/ui-smoke.js`：jsdom 全流程冒烟（开张→服务→日结→过夜，需 `NODE_PATH=<node_modules> node tests/ui-smoke.js`）

## 设计约束（对齐作者范式）

全部数值集中在 `BALANCE` 常量表；种子化可复现 RNG；存档 `kmg_save` 版本化；Web Audio 合成音效无音频文件；SVG 图标禁 Emoji；宣纸纸感 + 辣椒红单撞色；弹窗停表；结局生成可保存的 PNG 海报。
